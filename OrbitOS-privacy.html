OrbitOS

Privacy Policy

Effective date: November 27, 2026

1. Introduction

OrbitOS is a browser-based personal productivity extension designed to help users manage tasks, notes, bookmarks, projects, reminders and focus sessions.

OrbitOS is designed with a local-first approach that prioritizes user privacy, transparency and control over personal productivity data.

2. Information Stored

OrbitOS may store the following information provided or explicitly captured by the user:

  • Tasks and subtasks
  • Notes and descriptions
  • Bookmarks, webpage titles and URLs
  • Projects, collections and tags
  • Task reminders
  • Focus session records
  • Application preferences and settings
  • Relationships between productivity records

3. Local Data Storage

OrbitOS stores productivity information locally within the user's browser using IndexedDB and Chrome extension storage.

An account is not required to use the local productivity features.

Local storage is subject to the security protections of the user's browser, operating system and device. OrbitOS does not claim that locally stored information is independently encrypted.

4. Website Access

OrbitOS accesses webpage titles, URLs and selected text when the user explicitly requests bookmark capture or content saving.

OrbitOS does not continuously monitor browsing activity, collect browsing history for advertising, or automatically extract information from websites without user interaction.

5. Browser Permissions

OrbitOS uses browser permissions exclusively to provide its productivity functionality, including local storage, side panel access, user-initiated webpage capture, reminders and notifications.

Permissions are limited to those necessary for supported features.

6. Data Sharing and Advertising

OrbitOS does not sell personal information or use productivity data for targeted advertising.

The local-only version does not transmit productivity records to external servers.

User information is not used for creditworthiness assessments or lending purposes.

7. Analytics and Tracking

The local-only version of OrbitOS does not include third-party advertising trackers or remote behavioral analytics.

8. Data Export and Deletion

Users can export their supported workspace data using the backup functionality.

Users can delete individual records or clear their local workspace through the available data management settings.

Exported backup files are not encrypted by default and should be stored securely.

Uninstalling the extension or clearing browser data may result in the permanent removal of locally stored information.

9. Data Retention

Local productivity information remains stored on the user's device until the user deletes it, clears the application data, or removes the extension in a manner that deletes associated storage.

10. Children's Privacy

OrbitOS is a general-purpose productivity application and is not specifically directed toward children under the age of 13.

11. Google API Services User Data Policy

If applicable to future integrations, OrbitOS's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Any future integrations involving external data processing will require appropriate privacy disclosures.

12. Changes to This Privacy Policy

This privacy policy may be updated to reflect changes in OrbitOS functionality, legal requirements or data-handling practices.

The effective date will be updated when material changes are introduced.
